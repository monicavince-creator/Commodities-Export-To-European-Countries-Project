# 📊 Commodities Export Analysis to European Countries

## 📌 Project Overview

This project focuses on analyzing commodity exports from India to European countries using data-driven techniques. The goal is to evaluate export performance, identify revenue patterns, and provide actionable insights for improving business strategy.

The solution integrates data cleaning, transformation, and visualization to create an interactive dashboard that supports decision-making.

---

## 🎯 Objectives

* Calculate and analyze key metrics such as:

  * Total Revenue
  * Total Export Quantity
  * Average Unit Price
* Identify top-performing commodities and countries
* Understand trends and patterns in export data
* Provide recommendations for pricing, inventory, and market strategy
* Build a foundation for future sales forecasting

---

## 📂 Data Source

* **India Data Portal**
* Domain: Commerce
* Dataset includes export data such as commodity, country, quantity, value, and revenue

---

## 🧾 Dataset Features

* Date of export
* Country Name & Code
* Region & Sub-region
* Commodity Name & HS Code
* Unit of Measurement
* Quantity Exported

## 🔍 Key Insights

### 📌 Descriptive Insights

* Total Revenue: ₹31.72M
* Total Export Quantity: ~1.12M units
* Revenue is concentrated in a few high-performing commodities
* Netherlands is the top export destination

### 📌 Diagnostic Insights

* High-value commodities generate more revenue despite lower volume
* Low-value commodities dominate volume but reduce efficiency
* Pareto principle observed (80% revenue from 20% commodities)

### 📌 Predictive Insights

* Revenue shows cyclical trends (seasonality/policy impact)
* Export volume is stable, but revenue fluctuates due to pricing
* Growth depends on focusing on high-value commodities

### 📌 Prescriptive Insights

* Focus on high-value, low-volume products
* Optimize pricing strategies
* Strengthen markets like Netherlands, France, and Germany
* Reduce low ROI commodities
